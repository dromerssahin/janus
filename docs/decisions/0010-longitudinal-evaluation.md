# Longitudinal evaluation

Evaluation version 4 describes selected source events in an inclusive
index-relative window for included episodes. Event and recording days must be
available within the window and declared observation bounds. Output retains
episode identifiers, event IDs, relative event and recording days, and missing
reasons; these artifacts can be sensitive.

Counts of zero, one, and multiple observed events use completely covered
episodes as their denominator. Zero means no observed value, not proof that an
event did not occur, including when an explicit missing event exists. Event-day
distributions count observed events from all included episodes, including
incomplete and unknown coverage; missing events are counted separately.
Ordered pairs use the first observed event of each variable in completely
covered episodes. Their ordering and signed elapsed-day distributions use
episodes with both observed events as denominator; same-day events are ties.
The report also records the complete-coverage episode denominator.

These descriptive comparisons do not validate clinical plausibility, privacy,
causality, independent reference data, or censoring mechanisms. They do not fit
or generate trajectories.
