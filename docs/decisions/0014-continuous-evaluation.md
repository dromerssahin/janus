# Decision 0014: Continuous measurement evaluation

Numeric variables are evaluated only when explicitly selected in the optional
`continuous` configuration. Integer values are parsed exactly and floating
values must be finite. Reports retain observed, missing, absent, and invalid
states, descriptive moments, configurable interpolated quantiles, empirical
CDF distance, and optional patient-level bootstrap intervals. These are
conditional descriptive comparisons and do not establish clinical, causal,
privacy, independence, or external validity.
